# Linguist AI | Real-time Voice Translator

Linguist AI is a premium, real-time voice translation tool designed for seamless communication between English and Finnish. It leverages the browser's native Speech Recognition API for low-latency input and a high-performance translation engine for text output.

![Linguist AI Logo](translator_logo_1773213429480.png)

## ✨ Key Features
- **Live Voice Input**: Listens to speech in real-time.
- **Bi-directional Support**: Toggle between English -> Finnish and Finnish -> English.
- **Glassmorphism UI**: A stunning, modern interface with vibrant gradients and smooth animations.
- **Low Latency**: Shows interim speech results for immediate feedback.
- **Status Indicators**: Visual cues to show when the app is listening, ready, or busy.

## 🛠️ Technology Stack
- **Frontend**: HTML5, Vanilla CSS3, Modern JavaScript (ES6+).
- **APIs**: 
  - **Web Speech API**: For high-accuracy voice-to-text.
  - **MyMemory Translation API**: For fast, reliable text translation.
- **Design**: Google Fonts (Outfit), CSS Glassmorphism, Custom Animations.

## 🚀 How to Use
1. **Toggle Mode**: Use the switch at the top to select your source and target languages.
2. **Start Translating**: Click the large pulsate "Start Translating" button.
3. **Speak Clearly**: Your words will appear in the "Listening..." section as you speak.
4. **View Translation**: Once you stop speaking or a sentence is finished, the Finnish/English translation will appear on the right.

## 📂 File Structure
- `index.html`: Core structure and SEO-optimized markup.
- `style.css`: Premium aesthetics and layout.
